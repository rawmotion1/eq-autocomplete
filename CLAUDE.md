# eq-autocomplete: notes for Claude

A MacroQuest Lua script: a floating ImGui command box with autocomplete for commands, keywords
and live values, learning from what is typed. **Read `README.md` first**: keys, commands, files,
and a Status section. This file is the working knowledge that isn't obvious from the code.
Personal notes (whose machine, which characters, how to reach the game) are in `CLAUDE.local.md`,
which is git-ignored.

## Keep the repo shareable

The repo is meant to be shared. Nothing personal goes in it: no character, server or account
names, no one's command history or preferences, no paths from one machine. Tests use made-up
names (Aldric, Brenna). Everything the script learns or is set to lives in
`<MacroQuest>\config\eq-autocomplete\` (git-ignored patterns in `.gitignore` are a second guard).
Data read from paid plugins (CWTN) is read at run time and cached in that config folder, never
copied into the repo.

## The pieces

- `init.lua`: wiring, `/eqac`, main loop (refreshes live lists, runs queued lines with `mq.cmd`,
  applies the opening key, saves learning).
- `lib\grammar.lua` (tokenizer, grammar walker), `lib\engine.lua` (suggest, apply, record),
  `lib\learn.lua` (usage files): pure Lua, tested offline.
- `lib\sources.lua` (TLO reads, Magellan zones), `lib\ui.lua` (ImGui), `lib\hotkey.lua` (the
  opening key's binds), `lib\cwtn.lua` (CWTN class command): game only; type-checked, not unit-tested.
- `lib\commands.lua`: generated by `tools\build_commands.py` from three RedGuides pages (cached in
  `tools\cache\`, git-ignored). Never edit by hand; fixes go in `lib\extras.lua` or the script.
- Tests: `tests\run.ps1` (offline, fake sources) and `tests\check.ps1` (type check against
  `..\mq-definitions`). Run both after any Lua change. The language server's Lua is 5.5, so
  string.format('%-10q') and similar 5.1-isms behave differently there.

## Design decisions

- Grammar: the docs' syntax blocks are highlighted HTML (`nt` command, `nl`/`no` literal, `nv`
  placeholder, `p` punctuation). The script parses `{a|b}`, `[opt]`, `<placeholder>`, `...` into
  alternatives; unbalanced brackets are tolerated. Literals that are really placeholders
  (`CharName`, `options`, `zonename`, `//command`) are turned into placeholders by name.
  A keyword node may be `{k=word, d=description}` (used by the CWTN command to show values).
- Placeholder names decide the live list (`extras.sources`, overridable per command in
  `extras.commandSources`). `command`-type placeholders make the rest of the line a nested command;
  `text`-type ones (message, text...) are free text: no suggestions, not learned.
- Ranking: base per kind + usage bonus `12*log(1+n)` + recency; exact match +100 (so Tab on a fully
  typed word just adds a space); substring matches -40 (also on a value's `m`, e.g. a zone's long
  name). Ties: commands shortest-first (EQ abbreviations), arguments in syntax order. Extras'
  grammar lines are put first on purpose.
- Learning context: `<canonical command>|<arg number>|<previous word>`, plus a weaker positional
  fallback. Aliases resolve to the command they expand to, with the alias's own words prepended;
  an alias that wraps another command (`/cwtn = /dgge /docommand /${Me.Class.ShortName}`) resolves
  to the innermost one, and `${Me.Class.ShortName}` means this character's class command.
- One learned file per character (`learned_<server>_<name>.lua`) so parallel game windows never
  overwrite each other; all are read and summed. Up/Down recall uses only the own file's lines.
- Live lists are built in the main loop (TTL per kind, only while wanted), never during ImGui draw.
  Commands from the box are queued and run from the main loop too.
- Up/Down: moves the suggestion highlight when the list has items, otherwise history recall.
  Enter sends what is typed (it never accepts a suggestion). Right arrow completes only when the
  cursor was already at the end the frame before.

## The opening key (`/eqac key <combo>`, `lib\hotkey.lua`)

- Lua can't register key binds, so: a MQ2CustomBinds bind `eqac` on the key, down command
  `/docommand ${If[${Lua.Script[eq-autocomplete].Status.Equal[RUNNING]},/eqac slash,/lua run eq-autocomplete slash]}`,
  stored with `/noparse`. Only for plain "/" is MQ2CSCHAT (MQ2ChatWnd's bind, `MQ2CSCHAT_Nrm=/`
  by default) cleared.
- MQ2CustomBinds saves to `MQ2CustomBinds.txt` (blocks of `name=` / `down=` / `up=`), not to the
  `.ini` its docs' era used. Its reply to `set` (`[Down:...] [Up:...]`) shows what it stored.
- The bind commands run from the main loop (the `/eqac` handler only records the request),
  unsquelched and echoed, then the saved files are read back and the result printed.
- `settings.key` (combo or false) is in the shared settings.lua; each running copy re-reads it every
  10 s and applies it to its own window, squelched (binds are in memory per game window, read from
  the files at start). `settings.chatWas` keeps MQ2CSCHAT's key for undoing "/".
- Plain "/" did not work in practice: EQ's chat kept opening. A combo such as shift+/ does.

## CWTN class plugins (`lib\cwtn.lua`)

- The plugin's command is `/` + `Me.Class.ShortName` lower-cased. Which plugin: the file
  `config\CWTN\<Plugin>_<Name>.ini` for this character whose plugin is loaded (SHD's is MQ2EsKay,
  not an obvious name). `mq.TLO.CWTN.Mode()` answers when any CWTN plugin is loaded.
- Settings: every key in that ini (keys ending in a digit, like `StickHow0`, are slots and skipped);
  true/false/on/off/0/1 values get `on | off`. Actions: every `/%s Word` in the plugin DLL's help
  text; mode names from its `/%s Mode [0, 1, ... : manual, assist, ...]` string.
- Scanning the DLL (~3 MB) is cached in `config\eq-autocomplete\cwtn_cache.lua` by file size and
  date. In game the discovery took ~0.3-0.45 s either way, spread over frames by MacroQuest's
  per-frame Lua budget (no freeze observed); the cache mostly saves work.

## ImGui facts the UI relies on (MacroQuest's Lua binding)

- `ImGui.InputText*` takes a callback; MacroQuest calls it as `(x, data)` (other scripts use
  `function(_, data)`), so `ui.lua` takes `b or a`. `data.Buffer`, `data.CursorPos`,
  `data:DeleteChars`, `data:InsertChars`, `data.EventFlag`, `data.EventKey`.
- ImGui fires only one callback per frame: Completion (Tab) or History (Up/Down) or Always.
  The CallbackCompletion flag also stops Tab from moving focus.
- An active InputText ignores changes to the Lua string; text is changed inside the callback, or
  (after a mouse click on a suggestion) by setting `ui.pendingEdit` and refocusing.
- `ImGui.Selectable` returns `selected, clicked`; `ImGui.Begin(name, nil, flags)` returns `open, show`;
  `ImGui.GetColorU32(idx, alphaMul)` needs the second argument.
- **mq-definitions is not always right about return shapes.** In game `GetMouseDragDelta` returns
  one ImVec2 although the definitions say two numbers; adding it to a number crashed with
  `sol: no matching function ... __add`, which the type check can't catch. `ui.lua` reads every
  position/size through `xy()`, which takes either form; do the same for any new one.
- A Lua error between `ImGui.Begin` and `ImGui.End` leaves End uncalled: MacroQuest then reports
  "Missing End()" and pauses all ImGui until `/mqoverlay`. `draw` runs the window bodies in pcall
  and prints the error once instead.

## MacroQuest facts checked in game

- `DanNet.Peers()` is `name|name|...|` with lower-case names and the own name included (FullNames
  off; with it on, `server_name`). `DanNet.Groups()` has `all`, class groups, `group_<server>_<name>`,
  `zone_...`.
- Core plugins answer to `Plugin('MQ2ChatWnd')`, not the docs' section name `ChatWnd`; plugin
  names are case-insensitive. `mq.TLO.EQBC` is nil when MQ2EQBC isn't loaded.
- `Me.Ability(n)()` reads `false` for an empty button (so TLO answers are filtered for booleans).
- `mq.getAllSpawns()` is unsorted. `require('lfs')` works. `Lua.PIDs` includes exited scripts.
- `mq.parse('${Lua.Script[x].Status}')` is `NULL` for a script never run, so the opening key's
  If picks the "start it" branch.
- Magellan's `lua\magellan\zones.lua` returns `{[expansion] = {short = long}}` (about 600 zones).
